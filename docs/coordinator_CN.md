# 协调器模式

> 此功能存在于官方 Claude Code 代码库中但尚未完全发布。cc-mini 实现并发布了它。

协调器模式将助手转变为编排者，可以启动后台工作进程进行并行研究、实现和验证。

## 使用方法

```bash
cc-mini --coordinator
# 或
export CC_MINI_COORDINATOR=1
cc-mini
```

## 新增功能

- **后台工作进程** — 启动工作进程并在其运行时继续对话
- **继续流程** — 通过更多指令继续已完成的工作进程
- **任务通知** — 工作进程结果作为 `<task-notification>` 消息注入回来
- **会话感知恢复** — 恢复的会话自动恢复协调器模式

## 工作进程工具

| 工具 | 用途 |
|------|---------|
| `Agent` | 生成后台工作进程 |
| `SendMessage` | 通过任务 ID 继续现有工作进程 |
| `TaskStop` | 停止运行中的工作进程 |

## 典型工作流

1. 启动 `cc-mini --coordinator`
2. 请求较大的任务（研究、实现、验证）
3. 协调器在后台启动工作进程
4. 工作进程结果作为 `<task-notification>` 消息到达
5. 协调器综合结果并决定下一步

工作进程使用标准工具：`Read`、`Glob`、`Grep`、`Edit`、`Write`、`Bash`。
